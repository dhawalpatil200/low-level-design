# LLD (Low-Level Design) Problems

Repository for low-level design problems and documentation.

## Documentation

- **[Elevator System Design](awesomeLLDProblems/docs/elevator-system/design.md)** — Multi-elevator control system: requirements, entities, class diagram, and extensibility notes.
- **[Grocery Store System Design](awesomeLLDProblems/docs/grocery-store-system/design.md)** — Grocery store with catalog, inventory, checkout, and pluggable discount campaigns (criteria + calculation strategy).
- **[Logging Framework Design](awesomeLLDProblems/docs/logging-framework/design.md)** — Configurable logging with level filtering, pluggable appenders and formatters, and factory for named loggers.
- **[Unix File Search Design](awesomeLLDProblems/docs/unix-file-search/design.md)** — Recursive file search with pluggable, composable predicates (attribute comparisons and AND/OR/NOT).
- **[Parking Lot System Design](awesomeLLDProblems/docs/parking-lot-system/design.md)** — Parking lot with size-tiered spots, ticket on entry, and pluggable chainable fare strategies.
- **[Vending Machine Design](awesomeLLDProblems/docs/vending-machine/design.md)** — State-machine–driven vending machine with Idle/HasProduct/ReadyToDispense/Dispensing states and inventory (racks/products).
- **[Tic-Tac-Toe Design](awesomeLLDProblems/docs/tic-tac-toe/design.md)** — Two-player game with configurable board, turn enforcement, win/draw detection, and move history.
- **[Shipping Locker System Design](awesomeLLDProblems/docs/shipping-locker-system/design.md)** — Site with size-tiered lockers; packages assigned to smallest fitting locker and retrieved with time-limited access code.
- **[Movie Booking System Design](awesomeLLDProblems/docs/movie-booking-system/design.md)** — Cinema system: search screenings by movie/city/date, select seat (hold), pay and confirm for ticket; pluggable pricing and time-limited holds.

For the full docs structure and how to add new problems, see [docs/README.md](awesomeLLDProblems/docs/README.md).
